# Lummn

Lummn is a native iPhone, iPad and Mac app for browsing and backing up photos on your own
[Immich](https://immich.app) server, with full HDR display.

This repository is for **bug reports, feature requests and support**. The app's source code
isn't public.

- [Report a bug](https://github.com/magicsk/Lummn-issues/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/magicsk/Lummn-issues/issues/new?template=feature_request.yml)
- [Privacy policy](PRIVACY.md)

Before opening an issue, please search the existing ones. If your problem also happens in the
official Immich app or web interface, it's likely a server issue; report it to
[Immich](https://github.com/immich-app/immich/issues) instead.
